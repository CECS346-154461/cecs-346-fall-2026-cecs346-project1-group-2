# report/ - Project Report Folder

This folder contains the final report template for CECS 346 Project 1: Traffic Light Controller with Moore FSM and SysTick.

## Report Template

Complete the following file on the `step2-report` branch:

```text
Project_Report.md
```

The report template includes the required cover page, CSULB logo, project sections, tables, evidence links, team contribution section, reflection, references, and AI usage documentation.

## Instructions

- Create the `step2-report` branch from the updated `main` branch.
- Complete `Project_Report.md` using the provided section headings.
- Preserve the cover page and CSULB logo.
- Replace all placeholder text.
- Reference source code in `src/`.
- Reference testing evidence in `evidence/`.
- Include the FSM diagram and completed state table.
- Include the hardware schematic and system photographs.
- Include Logic Analyzer screenshots and test results.
- Include the on-board demonstration video link.
- Make sure the report matches the final source code and evidence.
- Commit meaningful report changes.
- Submit the completed report according to the Canvas instructions.

## Report Organization

The report should document the completed project, including:

- Project objective and system overview
- System requirements
- Hardware design and pin assignments
- Moore FSM design
- GPIO configuration and bit-specific address calculations
- SysTick timing calculations
- Software design and source files
- Simulator and hardware verification
- GitHub workflow and team contributions
- Challenges, solutions, and reflection
- References and AI usage

## Related Repository Folders

- `src/` - Source code
- `keil/` - Keil project files
- `docs/` - Project description and design documentation
- `evidence/simulator/` - Logic Analyzer and simulator evidence
- `evidence/hardware/` - Hardware schematics, photographs, and test results
- `evidence/demonstration/` - Demonstration video link and notes

## Report Guidelines

- Keep the report consistent with the final code and evidence.
- Use clear file names and readable screenshots.
- Include links to evidence files stored in this repository.
- Do not submit placeholder text as completed work.
- Do not include passwords, private access tokens, or other private information.
- Record AI assistance in `docs/AI_Log.md`.
- Do not rename or delete `Project_Report.md`.
