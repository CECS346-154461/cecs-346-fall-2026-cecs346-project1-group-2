# keil/ - Keil uVision Project Folder

This folder contains the Keil uVision project files for CECS 347 Project 1 - Ultrasonic Range Finder.

Open the project file in Keil to build, debug, and download the program to the TM4C123 LaunchPad.

## Folder Structure

```text
keil/
├── Project.uvprojx
├── Project.uvoptx
└── README.md
```

## Notes

* Do not rename or delete the Keil project files.
* Keep the Keil project connected to the source files in `src/`.
* Commit any project setting changes needed for your team’s code to build correctly.
