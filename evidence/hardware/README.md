# Hardware Evidence

Store physical LaunchPad, breadboard, wiring, and hardware test evidence for CECS 346 Project 1 in this folder.

## Include

- Hardware schematic
- Photograph of the completed system
- Switch wiring
- LED wiring
- Hardware test results
- Additional photographs that support the report

## Suggested File Names

```text
hardware_schematic.png
hardware_system_photo.jpg
switch_wiring.jpg
led_wiring.jpg
hardware_test_results.png
```

Do not place or remove wires while the circuit is powered. Make sure photographs clearly show the relevant connections.
